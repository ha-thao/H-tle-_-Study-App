# H-tle - Study App

A Python-based study application designed to support students in managing their academic activities and study-related tasks.

## Project Overview

**H-tle - Study App** is a study support application developed to provide students with several academic management and learning tools in one platform.

The application is built with Python and organized into multiple modules, including user login, GPA management, study planning, checklist management, lab-related activities, and training program management.

## Features

The application includes several study-related modules:

- **User Login** – Provides a login interface for accessing the application.
- **GPA Management** – Supports students in managing and working with their GPA information.
- **Study Management** – Provides study-related functionality for students.
- **Checklist** – Helps students organize and keep track of their study tasks.
- **Lab** – Provides functionality related to laboratory activities.
- **Training Program** – Supports students in managing information related to their training program.
- **Themes** – Provides shared theme-related components for the application.

## Technologies

- Python
- Python-based application modules
- Database management
